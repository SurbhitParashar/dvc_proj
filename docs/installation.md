# Installation

## Stable release

To install dvc_proj, run this command in your terminal:

```sh
uv add dvc_proj
```

Or if you prefer to use `pip`:

```sh
pip install dvc_proj
```

## From source

The source files for dvc_proj can be downloaded from the [Github repo](https://github.com/SurbhitParashar/dvc_proj).

You can either clone the public repository:

```sh
git clone https://github.com/SurbhitParashar/dvc_proj
```

Or download the [tarball](https://github.com/SurbhitParashar/dvc_proj/tarball/main):

```sh
curl -OJL https://github.com/SurbhitParashar/dvc_proj/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd dvc_proj
uv sync
```
